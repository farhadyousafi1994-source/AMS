# آموزش گام‌به‌گام سیستم آریا هرات مهندس‌زاده

یک مسیر آموزشی قدم‌به‌قدم. به همین ترتیب پیش بروید: اول **ورود و خروج** با هر حساب را یاد بگیرید،
بعد **تنظیمات مدیر** (کاربران، نقش‌ها، شعبات)، و سپس **کار روزمرهٔ هر نقش**. هر قدم می‌گوید روی چه
چیزی کلیک کنید و چه چیزی باید ببینید.

> زبان: در گوشهٔ بالا-راست دکمهٔ **EN / فارسی** است. با انتخاب فارسی، صفحه راست‌چین می‌شود.
> راهنمای کامل‌تر در `docs/GUIDEBOOK_FA.md` است.

## بخش ۱ — ورود و خروج (با هر حساب انجام دهید)

### ۱.۱ چگونه وارد شویم
1. آدرس برنامه را باز کنید.
2. در **ایمیل**، حساب را بنویسید (مثلاً `engineer@ariaherat.af`).
3. در **رمز**، بنویسید `password`.
4. روی **ورود** کلیک کنید.
5. وارد **داشبورد** می‌شوید. ✅

### ۱.۲ تغییر زبان
- بالا-راست، روی کرهٔ **EN ▾** کلیک و **فارسی** یا **English** را انتخاب کنید.

### ۱.۳ چگونه خارج شویم
1. در منوی کنار، پایین صفحه → **خروج (Logout)** (رنگ سرخ).
   *(یا از آواتار بالا-راست → خروج).*
2. به صفحهٔ ورود برمی‌گردید. ✅

### ۱.۴ تفاوت نقش‌ها را حس کنید — یکی‌یکی وارد شوید
برای هر حساب زیر: **وارد شوید**، به **منوی کنار** نگاه کنید، بعد **خارج شوید**. ببینید منو چطور
تغییر می‌کند — هر نقش فقط چیزی را می‌بیند که اجازه دارد.

- **`admin@ariaherat.af`** → **همه‌چیز**، شامل **اداره** و **سیستم**.
- **`president@ariaherat.af`** → نمای کلان شرکت + **مالی ← سهم‌داران**.
- **`engineer@ariaherat.af`** → **پروژه‌ها، مدیریت ساحه، صورت‌حساب، ایمنی** — بدون اداره.
- **`supervisor@ariaherat.af`** → بیشتر **مدیریت ساحه** (درخواست خرید، حاضری، کارگران).
- **`accountant@ariaherat.af`** → **مالی و حسابداری** به‌طور کامل.
- **`storekeeper@ariaherat.af`** → **تدارکات و دارایی‌ها** (سفارش خرید، گدام).
- **`viewer@ariaherat.af`** → صفحات را باز می‌کند اما دکمه‌های **افزودن/ویرایش/حذف** پنهان‌اند.

✅ **کنترل:** می‌توانید با هر حساب وارد و خارج شوید، زبان را عوض کنید، و می‌دانید منو وابسته به نقش است.

## بخش ۲ — تنظیمات مدیر (با `admin@ariaherat.af` وارد شوید)

مدیر اول این‌ها را تنظیم می‌کند: **شعبه ← نقش ← کاربر**.

### قدم ۱ — ساختن شعبه
1. منو → **اداره ← شعبه (Branch)**.
2. **افزودن شعبه** (بالا-راست).
3. **نام** (مثلاً `دفتر ساحه هرات`)، آدرس، تلفن.
4. **ذخیره**. شعبه در لست ظاهر می‌شود. ✅

### قدم ۲ — ساختن نقش و انتخاب دسترسی‌ها
*(مثال: نقش «کارمند منابع بشری».)*
1. منو → **اداره ← نقش کاربر (User Role)**.
2. **افزودن نقش**.
3. **نام:** `کارمند HR`.
4. باکس‌های لازم را تیک بزنید — برای HR، **کارمند، حاضری، معاش، رخصتی، دیپارتمنت، بست** را تیک بزنید
   (لست/ایجاد/ویرایش/نمایش). مالی و اداره را تیک نزنید.
5. **ذخیره**. ✅
   *(بعداً هر نقش را باز کرده می‌توانید یک ماژول کامل را تیک بزنید — مثلاً دسترسی **حوادث ایمنی** با تیک `incident`.)*

### قدم ۳ — ساختن کاربر و دادن نقش + شعبه
1. منو → **اداره ← کاربر (User)**.
2. **افزودن کاربر**.
3. **نام**، **ایمیل** (مثلاً `hr@ariaherat.af`)، **رمز**.
4. **نقش:** `کارمند HR` (از قدم ۲).
5. **شعبه(ها):** یک یا چند شعبه بدهید. یک کاربر می‌تواند **در شعبه‌های مختلف نقش‌های مختلف** داشته باشد.
6. **ذخیره**. ✅

### قدم ۴ — تأیید (و تغییر رمز)
1. **خارج شوید**.
2. با کاربر جدید (`hr@ariaherat.af`) **وارد شوید** → ببینید فقط منوی HR را دارد.
3. برای تغییر رمز: **اداره ← کاربر ← (ویرایش کاربر) ← رمز جدید ← ذخیره.**

### تنظیمات اختیاری مدیر
- **اسعار و نرخ تبادله:** مالی ← **اسعار / نرخ تبادله** (نرخ امروز افغانی↔دالر را ثبت کنید).
- **آرم و نام شرکت:** در PDFهای صادرشده و سربرگ برنامه استفاده می‌شود.

✅ **کنترل:** یک شعبه، یک نقش و یک کاربر ساختید و دسترسی کاربر جدید را تأیید کردید.

## بخش ۳ — کار روزمرهٔ هر نقش

### ۳.۱ مالک / رئیس / سهم‌دار — `president@` (یا `abubakr@`, `omar@`, `usman@`, `ali@`)
1. **داشبورد** → نقشهٔ شرکت و کارت‌های خلاصه.
2. **مالی ← سهم‌داران** → چهار کارت شریک، هرکدام ۲۵٪.
3. برای **برداشت**: روی **برداشت** یک شریک کلیک → مبلغ → **ذخیره**.
   *(به خزانه و تاریخچهٔ شریک ثبت می‌شود. بیش از موجودی مجاز نیست.)*
4. پایین صفحه: **واریز/برداشت همهٔ سهم‌داران** (شفافیت).
5. **گزارشات** → **سود و زیان** → **صدور PDF**.

### ۳.۲ انجنیر پروژه — `engineer@ariaherat.af`
1. **پروژه‌ها ← پروژه‌ها و ساحات** → **افزودن پروژه**.
2. **نام، بودجه، اسعار، مشتری، نوع، شعبه، تاریخ‌ها** را پر کنید.
3. **مهم — موقعیت را روی نقشه انتخاب کنید:** در باکس نقشه، روی محل کلیک کنید (پین سرخ می‌افتد و
   مختصات نشان داده می‌شود). **بدون این کار، پروژه در نقشهٔ داشبورد ظاهر نمی‌شود.**
4. **ایجاد و ادامه** → در تب‌ها **وظایف، مراحل، ساحات** را اضافه کنید.
5. بعداً پروژه را باز کرده و **پیشرفت یک وظیفه** را تغییر دهید؛ **فیصدی پروژه خودکار** به‌روز می‌شود.
6. **تغییر قرارداد:** پروژه‌ها ← **تغییرات قرارداد ← افزودن** → با **تأیید**، ارزش قرارداد خودکار اصلاح می‌شود.
7. به **داشبورد** برگردید → پروژهٔ جدید به‌عنوان **پین نقشه** و **برج** نشان داده می‌شود. ✅

### ۳.۳ سوپروایزر ساحه — `supervisor@ariaherat.af` (بهتر روی موبایل؛ آفلاین کار می‌کند)
1. **مدیریت ساحه ← درخواست‌های خرید ← افزودن** → اقلام + **عکس بل را ضمیمه** → ذخیره.
2. **مدیریت ساحه ← حاضری ساحوی** → پروژه/تاریخ → حاضر/غیرحاضر.
3. **مدیریت ساحه ← کارگران** → کارگر جدید (نام، حرفه، مزد، عکس).
4. **آرشیف فاکتورها** → عکس بل‌های بایگانی‌شده.
5. **آزمایش آفلاین:** وای‌فای را خاموش کنید → یک درخواست خرید بسازید (در صف می‌رود) → وای‌فای را روشن کنید
   → **سیستم ← مرکز همگام‌سازی** → بعد از همگام‌سازی **۰ معلق** نشان می‌دهد. ✅

### ۳.۴ سرویر / صورت‌حساب — (کاربر با دسترسی صورت‌حساب، مثلاً `engineer@`)
1. **صورت‌حساب ← صورت مقادیر (BOQ)** → پروژه را انتخاب → **افزودن** اقلام (شماره، واحد، مقدار، نرخ).
2. **صورت‌حساب ← اسناد پرداخت ← سند جدید** → **مقدار تجمعی انجام‌شده** هر قلم را وارد کنید → سیستم
   **این‌دوره، حسن‌اجرا، قابل‌پرداخت خالص** را زنده حساب می‌کند.
3. **ذخیرهٔ پیش‌نویس ← تأیید ← چاپ**. ✅

### ۳.۵ محاسب / مالی — `accountant@ariaherat.af`
1. **مالی ← بودجهٔ عمومی** → ورودی/خروجی و موجود.
2. **مالی ← رسیدها ← افزودن** → دریافت پول از مشتری.
3. **مالی ← مصارف خانه ← افزودن** → دسته و **طریقهٔ تادیه**. اگر **سایر** را انتخاب کنید،
   خانهٔ **«لطفاً توضیح دهید»** ظاهر می‌شود.
4. **مالی ← حسابات (قرض/طلب)** → بیلانس هر طرف.

### ۳.۶ گدام‌دار / تدارکات — `storekeeper@ariaherat.af`
1. **تدارکات و دارایی‌ها ← سفارش‌های خرید ← افزودن** → اقلام، تهیه‌کننده، و **ضمیمهٔ بل**.
2. **تدارکات و دارایی‌ها ← تهیه‌کنندگان**.
3. **تدارکات و دارایی‌ها ← گدام** → اقلام و حرکت اجناس.

### ۳.۷ مدیر ماشین‌آلات — (کاربر با دسترسی ماشین‌آلات)
1. **تدارکات و دارایی‌ها ← ماشین‌آلات و تیل ← افزودن** → ماشین، ساعات کارکرد، لیتر، قیمت فی لیتر، راننده.
2. کارت‌ها: **مجموع تیل، هزینه، ساعات، مصرف اوسط**. عکس بل تیل را ضمیمه کنید.

### ۳.۸ مسئول ایمنی (HSE) — (کاربر با دسترسی ایمنی)
1. **ایمنی و کیفیت ← حوادث ایمنی ← ثبت حادثه** → نوع، شدت، محل، مجروحین، اقدام فوری → ذخیره.
2. بعداً **بستن حادثه** با اقدام اصلاحی؛ در صورت نیاز بازگشایی.

### ۳.۹ منابع بشری — (کاربر `کارمند HR` که در بخش ۲ ساختید، یا `admin@`)
1. **منابع بشری ← کارمندان ← کارمند جدید** (صفحهٔ کامل) → معلومات + عکس → ذخیره.
2. **منابع بشری ← حاضری** → حاضری روزانهٔ کارمندان.
3. **منابع بشری ← لست معاش** → اجرای معاش؛ **رخصتی‌ها** → مدیریت رخصتی.

### ۳.۱۰ بیننده / مفتش — `viewer@ariaherat.af`
1. هر صفحه را باز کنید (پروژه، مالی، گزارش) — می‌توانید **ببینید و صادر کنید**، اما هیچ دکمهٔ
   **افزودن/ویرایش/حذف** نیست. مناسب برای مفتشین.

## بخش ۴ — کارهای سیستم (مدیر)

- **سیستم ← مرکز همگام‌سازی** → وضعیت اتصال، تغییرات معلق، و **بررسی تعارض‌ها**
  (نگه‌داشتن مال من / نگه‌داشتن سرور).
- **سیستم ← پشتیبان** → **دانلود پشتیبان**؛ **بازیابی/وارد کردن** (اول به‌طور خودکار نسخهٔ محافظتی می‌گیرد).
- **سیستم ← لاگ** → چه‌کسی چه‌کاری کرد. **زباله‌دان** → بازیابی حذف‌شده‌ها.
- **سیستم ← ظاهر/تم**.

## ضمیمه — دو پرسش رایج

1. **«پروژهٔ جدیدم در داشبورد/نقشه نیست.»**
   - مطمئن شوید هنگام ساختن، **موقعیت را روی نقشه انتخاب کرده‌اید** (بخش ۳.۲ قدم ۳).
   - سازندهٔ پروژه خودکار عضو آن می‌شود، پس بلافاصله برایش قابل‌دیدن است.
2. **صدور PDF/Word** همیشه **آرم، نام شرکت و تاریخ** را دارد و **متن فارسی درست** صادر می‌شود.
